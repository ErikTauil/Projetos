# 🎬 Análise de Dados com Python - Notas de Filmes

Este projeto é uma análise exploratória dos dados de avaliações de filmes do dataset [MovieLens](https://grouplens.org/datasets/movielens/latest/), utilizando Python e bibliotecas como "Pandas", "Matplotlib"
e "Seaborn".  
Foi inspirado nas aulas da formação em Data Science com Erik Tauil.

---

## 🧠 Objetivos do Projeto

- Carregar e explorar dados reais de avaliações de filmes
- Entender a distribuição das notas
- Calcular médias e frequências
- Visualizar os dados de forma clara e objetiva
- Praticar análise de dados com Python e Pandas

## 📊 Etapas da Análise

1. **Importação dos Dados**
   - ratings.csv (notas dos filmes)
   - movies.csv (títulos e gêneros)

2. **Renomeação de Colunas**
   - Facilita o entendimento e escrita do código

3. **Análise Descritiva**
   - Valores únicos
   - Frequência de notas
   - Média e mediana

4. **Visualização dos Dados**
   - Histograma de notas
   - Boxplot
   - Distribuição das médias dos filmes

5. **Análise Individual por Filme**
   - Toy Story, Jumanji, etc.
   - Médias por ID de filme

---

## 📈 Principais Resultados

- A média geral das notas é de **3.50**
- A mediana também é **3.5**, indicando distribuição relativamente simétrica
- A maioria das notas está entre **3 e 4**
- O filme **Toy Story** tem média de **3.92**, enquanto **Jumanji** tem média de **3.43**
