# 📊 Análise de Vendas - Power BI

## 🔍 Objetivo
Este projeto tem como objetivo analisar os dados de vendas de uma empresa fictícia, identificando os principais indicadores de desempenho (KPIs), como:
- Total de vendas por região
- Vendas por canal de distribuição
- Produtos mais vendidos
- Variações mensais e tendências

## 🧰 Ferramentas Utilizadas
- **Power BI**: construção do dashboard
- **Excel / CSV**: manipulação de base de dados
- **Power Query**: tratamento dos dados
- **DAX**: fórmulas e medidas personalizadas

## 🗂️ Estrutura dos Arquivos
- `vendas.pbix` → Dashboard interativo no Power BI
- `dados.csv` → Base de dados bruta de vendas
- `insights.txt` → Documento com principais descobertas
- `README.md` → Documentação do projeto

## 📈 Etapas do Projeto
1. Importação e limpeza dos dados no Power BI (Power Query)
2. Criação de medidas com DAX para:
   - Receita total
   - Quantidade vendida
   - Ticket médio
3. Segmentações por:
   - Região
   - Mês
   - Canal
4. Criação de gráficos e visuais interativos
5. Geração de insights e storytelling com base nos dados

## 💡 Principais Insights
- A Região Sudeste representa mais de 40% das vendas totais.
- O Canal "E-commerce" superou o canal físico em 3 dos últimos 6 meses.
- O produto **Linha Premium X** tem o maior ticket médio, mas baixa frequência de venda.
- Tendência de crescimento de vendas no 2º semestre.

## 🧠 Aprendizados
- Prática com modelagem de dados e relacionamento no Power BI
- Escrita de medidas com DAX
- Construção de dashboards profissionais com storytelling visual
