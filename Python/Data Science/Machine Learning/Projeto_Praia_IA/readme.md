
🏖️ Simulador de Decisão com IA

🚀 Uma aplicação de Inteligência Artificial que aprende a decidir se vale a pena ir à praia

📌 Sobre o Projeto

Este projeto é um simulador interativo que utiliza Inteligência Artificial para tomar decisões com base em diferentes condições do dia a dia.

A aplicação analisa fatores como:

☀️ Clima (Sol)
🚗 Trânsito
💰 Dinheiro disponível
👥 Companhia (amigos)

Com base nesses dados, a IA decide:

👉 “PARTIU PRAIA”
ou
👉 “Melhor ficar em casa”

🎯 Objetivo

O objetivo do projeto é demonstrar, de forma simples e prática, como modelos de Machine Learning podem:

Aprender padrões a partir de dados
Tomar decisões baseadas em probabilidades
Simular comportamentos do mundo real

Além disso, o projeto serve como portfólio prático para aplicações de IA em cenários do cotidiano.

🧠 Como Funciona

A aplicação utiliza uma Rede Neural Artificial para aprender com dados previamente definidos.

O fluxo é:

O modelo é treinado com diferentes cenários (dados históricos simulados)
O usuário informa as condições atuais
A IA processa os dados
O modelo retorna:
Decisão (Ir ou não à praia)
Probabilidade da decisão
Explicação dos fatores envolvidos
🤖 Modelo de IA

Foi utilizada uma rede neural do tipo:

👉 MLPClassifier (Multi-Layer Perceptron)

Características:

Rede neural com múltiplas camadas
Capaz de aprender padrões não lineares
Utiliza treinamento supervisionado
Baseada em ajuste de pesos (backpropagation)
